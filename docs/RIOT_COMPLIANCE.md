# Riot Developer Policy Compliance Matrix (`v2.2.0`)

BetterJungler is designed from the ground up to comply with [Riot Games Developer Policies](https://developer.riotgames.com/docs/lol).

| Policy Requirement | How BetterJungler Enforces It | Verification / Code Location |
|---|---|---|
| **No Memory Reading / Process Injection (Vanguard Safe)** | Zero memory reading, DLL injection, or packet sniffing. Uses only official Riot Web API, Data Dragon CDN, LCU HTTPS REST API, and Live Client / Replay Data API (`127.0.0.1:2999`). | `src-tauri/src/lcu.rs`, `src-tauri/src/live_client.rs`, `src-tauri/src/replay_api.rs`, `src-tauri/src/riot_api.rs` |
| **Opt-In Windows Graphics Capture (No DXGI/DLL Hooking)** | Gameplay recording is **Off by default** (`enabled: false`), verifies hardware H.264 MFT presence (`NVENC`/`AMF`/`QuickSync` via `MFTEnumEx`) before encoding, captures strictly the `League of Legends (TM) Client` HWND via OS `Windows.Graphics.Capture`, excludes Alt-Tab windows and BetterJungler overlays, and enforces scoped `$APPDATA/recordings/**` CSP + disk quota pruning. | `src-tauri/src/recorder.rs`, `src-tauri/src/storage.rs`, `src-tauri/tauri.conf.json`, `src/components/settings/RecordingSettingsSection.tsx` |
| **Official Riot Local Replay API & Explicit `game.cfg` Opt-In** | Optional zero-overhead `.rofl` discovery (`Documents\League of Legends\Replays`) and Replay API seek (`https://127.0.0.1:2999/replay/playback`). Never silently modifies Riot files; writes `EnableReplayApi=1` strictly on explicit user button click with a `.cfg.bak` backup. | `src-tauri/src/replay_api.rs`, `src/components/RecordingPlayerCard.tsx`, `src/components/settings/RecordingSettingsSection.tsx` |
| **Ranked Solo/Duo Champ Select Anonymity & Inferred Role Honesty** | Non-local/non-party player identities in Champ Select are masked to `Ally 1..5` and `Enemy 1..5` in both Rust and TypeScript. Enemy Bot lane assignments inferred from public picks in Solo/Duo are always explicitly labeled `Likely`. | `src-tauri/src/lcu.rs::sanitize_champ_select`, `src/domain/champSelectEngine.ts::sanitizeChampSelectSession`, `src/domain/adc/adcDraftEngine.ts`, `src/components/ChampSelectView.tsx` |
| **No Automated Gameplay / Queue / Draft Actions** | BetterJungler NEVER auto-accepts queues, auto-bans, or auto-picks champions. Rune & summoner spell import executes strictly on explicit user button click via verified per-patch allowlists (`Jungle` and `ADC` rune specs). | `src-tauri/src/lcu.rs::apply_runes_and_spells`, `src/components/ChampSelectView.tsx` |
| **No Enemy Ultimate Cooldown Trackers or Hidden Information** | Does not track, estimate, or display enemy ultimate cooldowns, off-screen summoner timers, or fog-of-war locations. Live coaching and capped macro guardrails enforce compile-time `never` type exclusions on forbidden telemetry fields. | `src/types/coaching.ts`, `src/domain/liveCoachEngine.ts`, `src/domain/adc/adcLiveEngine.ts`, `src/domain/winConditionEngine.ts` |
| **Grounded AI Output Guardrails (Optional BYOK)** | Optional BYOK post-game and win-plan AI narratives cross-check generated numeric tokens and role claims against deterministic match telemetry, rejecting hallucinated or cross-role claims. | `src-tauri/src/ai_coach.rs`, `src/domain/aiFactValidator.ts` |
| **Role-Clean Live Coaching Suppression** | In Top, Mid, or Support off-role matches, role-specific Smite trackers, jungle routes, and jungle/ADC item suggestions are suppressed cleanly; only public global objective timers remain active. | `src/domain/sessionContext.ts`, `src/domain/hudModel.ts`, `src/HudApp.tsx`, `src/components/LiveCoachView.tsx` |
| **Ed25519 Signed Patch Packs** | Knowledge packs (`knowledge/<patch>.json`) verify canonical length-prefixed Ed25519 signatures against the pinned public key with anti-rollback version guards, falling back safely to verified embedded defaults if tampered. | `src-tauri/src/patch_pack.rs`, `scripts/sign-patch-pack.mjs` |
| **Distinct Ad-Free Two-Window UI** | Material Design 3 Expressive companion window + isolated dark glass tactical HUD overlay (`hud.html`) remain visually distinct from Riot's Hextech UI and carry zero ads. | `src/styles/m3-expressive.css`, `src/styles/globals.css`, `src/components/hud/HudOverlayCanvas.tsx` |
| **Mandatory Riot Legal Disclaimer** | Displayed persistently in the app footer, `Updates & About` documentation context, and [`README.md`](../README.md). | `src/App.tsx`, `README.md` |
| **API Key Protection & Rate Limiting** | Riot & AI Coach API keys are stored strictly in Windows Credential Manager (`keyring`), never logged; optional HTTPS proxy (`proxy/`) injects `RIOT_API_KEY` server-side with `X-App-Client`, host/prefix allowlists, traversal rejection, and per-IP caps; `RiotRateLimiter` enforces `Retry-After` and bucket headers. | `src-tauri/src/storage.rs`, `src-tauri/src/rate_limiter.rs`, `src-tauri/src/riot_api.rs`, `proxy/src/index.ts` |
