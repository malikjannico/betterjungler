# Riot Developer Policy Compliance Matrix

BetterJungler is designed from the ground up to comply with [Riot Games Developer Policies](https://developer.riotgames.com/docs/lol).

| Policy Requirement | How BetterJungler Enforces It | Verification / Code Location |
|---|---|---|
| **No Memory Reading / Process Injection (Vanguard Safe)** | Zero memory reading, DLL injection, or packet sniffing. Uses only Riot Web API, Data Dragon, LCU HTTPS REST API, and Live Client / Replay Data API (`127.0.0.1:2999`). | `src-tauri/src/lcu.rs`, `src-tauri/src/live_client.rs`, `src-tauri/src/replay_api.rs`, `src-tauri/src/riot_api.rs` |
| **Opt-In Windows Graphics Capture (No DXGI/DLL Hooking)** | Gameplay recording is **Off by default** (`enabled: false`), verifies hardware H.264 MFT adapter presence (`NVENC`/`AMF`/`QuickSync` probe via `MFTEnumEx`) before encoding via OS Media Foundation H.264, captures strictly the `League of Legends (TM) Client` HWND via OS `Windows.Graphics.Capture`, excludes Alt-Tab windows and BetterJungler overlays, and enforces scoped `$APPDATA/recordings/**` CSP & hard disk quota pruning. | `src-tauri/src/recorder.rs`, `src-tauri/src/storage.rs`, `src-tauri/tauri.conf.json` |
| **Official Riot Local Replay API & Explicit `game.cfg` Opt-In** | Optional zero-overhead `.rofl` discovery (`Documents\League of Legends\Replays`) and Replay API seek (`https://127.0.0.1:2999/replay/playback`). Never silently modifies Riot files; writes `EnableReplayApi=1` strictly on explicit user button click with a `.cfg.bak` backup. | `src-tauri/src/replay_api.rs`, `src/components/RecordingPlayerCard.tsx`, `src/components/SettingsView.tsx` |
| **Ranked Solo/Duo Champ Select Anonymity** | Non-local/non-party player identities in Champ Select are masked to `Ally 1..5` and `Enemy 1..5` in both Rust and TypeScript. | `lcu.rs::sanitize_champ_select`, `src/domain/champSelectEngine.ts::sanitizeChampSelectSession` |
| **No Automated Gameplay / Queue / Draft Actions** | BetterJungler NEVER auto-accepts queues, auto-bans, or auto-picks champions. Rune & spell import runs ONLY on explicit user button click. | `lcu.rs::apply_runes_and_spells`, `ChampSelectView.tsx` |
| **No Enemy Ultimate Cooldown Trackers** | Does not track, estimate, or display enemy ultimate or off-screen summoner spell cooldowns. | `src/domain/liveCoachEngine.ts` |
| **No Hidden Information / Fog-of-War Bypass** | Live coaching relies solely on official visible state (game clock, visible items, KDA, public kill/objective events). Path/ward planning happens pre-game via strategic principles. | `src/domain/winConditionEngine.ts`, `src/domain/liveCoachEngine.ts` |
| **Distinct Overlay UI & Ad-Free** | Uses an original Obsidian/Slate tactical HUD aesthetic distinct from Riot's Hextech UI, with zero ads. | `src/styles/globals.css`, `src/components/CompactHudBar.tsx` |
| **Mandatory Riot Legal Disclaimer** | Displayed persistently in the app footer, Settings view, and `README.md`. | `src/App.tsx`, `src/components/SettingsView.tsx`, `README.md` |
| **API Key Protection & Rate Limiting** | Personal Riot API keys are stored in Windows Credential Manager (`keyring` `windows-native`), never committed or logged; optional zero-trust HTTPS proxy mode (`proxy/` Cloudflare Worker) injects `RIOT_API_KEY` server-side with `X-App-Client`, host/prefix allowlists, traversal rejection, and per-IP rate limiting; shared `RiotRateLimiter` honors `Retry-After` + `X-App-Rate-Limit-Count` headers with strict `Platform` allowlisting and TLS pinning (`riotgames.pem`) for loopback LCU/Live Client connections. | `src-tauri/src/storage.rs`, `src-tauri/src/rate_limiter.rs`, `src-tauri/src/riot_api.rs`, `src-tauri/src/lcu.rs`, `proxy/src/index.ts` |
